# Santé Initiative Uganda - Backend

Backend API for the Santé Initiative Uganda vision health app. This app is designed for community health workers in Uganda to screen clients, sell reading glasses, and track mobile money payments.

## Features

- User authentication (via phone number OTP)
- Client screening data management
- Product and inventory management
- Mobile money payment tracking
- Offline data synchronization

## Technology Stack

- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** PostgreSQL
- **Authentication:** JWT (JSON Web Tokens)
- **Payment Integration:** Mobile Money API (MTN MoMo, Airtel Money)

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- PostgreSQL (v12 or higher)
- npm or yarn

### Installation

1. Clone the repository
2. Navigate to the backend directory:
   ```bash
   cd backend
   ```
