### How It Works:

1. **User requests OTP:**
   ```bash
   POST /api/auth/login
   {"phoneNumber": "0700123456"}
   ```

2. **Twilio sends SMS:**
   - 6-digit code generated by Twilio
   - Sent via SMS to user's phone
   - Valid for 10 minutes

3. **User verifies OTP:**
   ```bash
   POST /api/auth/verify-otp
   {"phoneNumber": "0700123456", "otp": "123456"}
   ```

4. **System responds:**
   - JWT token for authentication
   - User data

### Features:
- ✅ Works with ANY phone number (upgraded account)
- ✅ Automatic OTP generation by Twilio
- ✅ Automatic expiration (10 minutes)
- ✅ Secure verification via Twilio Verify API
- ✅ No OTP stored in database (handled by Twilio)
